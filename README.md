# NeWCheers

[日本語](https://github.com/hjy0221/NewCheers#%E6%97%A5%E6%9C%AC%E8%AA%9E) · [English](https://github.com/hjy0221/NewCheers#english) · [한국어](https://github.com/hjy0221/NewCheers#%ED%95%9C%EA%B5%AD%EC%96%B4)

## 日本語

NeWCheers は、チームメンバー同士で応援メッセージを送り合う流れを試す SwiftUI 製 iOS プロトタイプです。

### 主な画面

- ログインと新規登録
- メンバーの選択、シャッフル、スキップ
- 受信通知と応援相手の確認
- プロフィールとマイページ
- `NavigationStack` による画面遷移

### 実行方法

1. Xcode で `Cheers.xcodeproj` を開きます。
2. iOS シミュレーターまたは接続したデバイスを選択します。
3. Run ボタンでアプリを起動します。

### 技術

Swift、SwiftUI、Xcode。

## English

NeWCheers is a SwiftUI iOS prototype that explores a flow for exchanging supportive messages with teammates.

### Main screens

- Sign in and sign up
- Teammate selection with shuffle and skip actions
- Received notification list and recipient confirmation
- Profile and account pages
- Screen navigation built with `NavigationStack`

### Run locally

1. Open `Cheers.xcodeproj` in Xcode.
2. Select an iOS Simulator or a connected device.
3. Press Run to launch the app.

### Tech stack

- Swift
- SwiftUI
- Xcode

## 한국어

NeWCheers는 팀원과 응원 메시지를 주고받는 흐름을 실험한 SwiftUI 기반 iOS 프로젝트입니다.

### 주요 화면

- 로그인 및 회원가입
- 팀원 선택과 셔플·건너뛰기 동작
- 받은 알림 목록과 응원 대상 확인
- 프로필 및 마이페이지
- `NavigationStack`을 사용한 화면 이동

### 실행하기

1. Xcode에서 `Cheers.xcodeproj`를 엽니다.
2. 원하는 iOS Simulator 또는 연결된 기기를 선택합니다.
3. Run 버튼을 눌러 앱을 실행합니다.

### 기술 스택

- Swift
- SwiftUI
- Xcode
