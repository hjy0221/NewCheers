# NeWCheers

[日本語](README.ja.md) · [English](README.md) · [한국어](README.ko.md)

NeWCheers는 팀원과 응원 메시지를 주고받는 흐름을 실험한 SwiftUI 기반 iOS 프로젝트입니다.

### 주요 화면

- 로그인 및 회원가입
- 팀원 선택과 셔플·건너뛰기 동작
- 받은 알림 목록과 응원 대상 확인
- 프로필 및 마이페이지
- `NavigationStack`을 사용한 화면 이동

### 실행하기

1. Xcode에서 `Cheers.xcodeproj`를 엽니다.
2. 원하는 iOS Simulator 또는 연결된 기기를 선택합니다.
3. Run 버튼을 눌러 앱을 실행합니다.

### 기술 스택

- Swift
- SwiftUI
- Xcode
